## Key Learnings Today

1. **Prisma schema mismatches are silent killers** - The `globalFreezeEnabled` field didn't exist but code tried to select it. No type error at compile time, just runtime failure.

2. **Debug logging is essential** - Added console.log to apply-plan route, which finally revealed the actual error in Render logs.

3. **Test E2E before declaring victory** - Had all phases "done" but apply-plan was broken. Full flow testing caught it.

4. **JWT sessions + middleware = watch your token** - Middleware `getToken()` only works with JWT strategy, not database sessions.

5. **Model availability matters** - Goal executor failed because explicit model (claude-sonnet-4) wasn't allowed. Using defaults is safer.
