## PP Onboarding Bug — Root Cause Found
- **Symptom:** New users see "Primary repository is not configured" on activation page after installing GitHub App
- **Root cause:** `GITHUB_APP_PRIVATE_KEY` on Render was PKCS#1 format (`BEGIN RSA PRIVATE KEY`). The app uses `crypto.subtle.importKey('pkcs8', ...)` which requires PKCS#8 format. The custom PKCS#1→PKCS#8 ASN.1 wrapper in `jwt.ts` has a bug with multi-byte length encoding on Render's Node version.
- **Effect:** Every JWT generation failed silently → `verifyGitHubInstallationForUser` failed → `linkInstallationToCompany` never ran → repos never synced → `primaryRepoFullName` stayed null
- **Fix:** Replaced Render env var with PKCS#8 format key (`BEGIN PRIVATE KEY`). Deploying now.
- **Duration:** Bug existed since at least April 1 (7+ days). Zero `[link-installation]` logs in production for a week.
