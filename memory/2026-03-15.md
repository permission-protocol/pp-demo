## Key Lessons
- **Conflict cascades are real**: When merging 7+ PRs to the same repo, later PRs WILL conflict. Next time: merge in dependency order and rebase remaining branches after each merge.
- **Live QA during merge is gold**: Found 3 bugs Rod would have hit in production. Always dogfood during merge sprints.
- **Factory pipeline scales**: 14 PRDs → 14 builds → 14 QAs in parallel across 2 repos. The bottleneck is Codex execution time (~3-5 min per build), not orchestration.
- **pr-gate.yml environment was wrong since setup**: Nobody caught `staging` until the environment badges made it visible. UX improvements surface config bugs.
