## Key Lessons
- **R1 doesn't support tool use** through OpenClaw agent sessions — only works for direct prompting via curl. Use it for reasoning/judgment/content, not for tasks needing GitHub/board tools.
- **zsh vs bash gotcha:** `${var,,}` for lowercase is bash-only. Use `tr '[:upper:]' '[:lower:]'` for portability.
- **Shell quoting in Python -c:** Use env vars (`R1_MODEL="$MODEL" python3 -c 'import os; os.environ["R1_MODEL"]'`) instead of trying to interpolate shell vars inside Python string literals.
