## Key Design Decisions
- **PWA first, not native app** — web push + add-to-homescreen, native only if push limitations force it
- **Cards not tables** on mobile — every request is a self-contained decision unit
- **Inline approve on queue cards** — don't force navigation to detail page for routine deploys
- **Urgency sort** (production + risk + age) instead of chronological
- **Batch approve** only when ALL pending are low-risk + non-production (safety gate)
- **Critical alert card** — for critical-risk production, no inline approve, forces detail page review
