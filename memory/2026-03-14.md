## GitHub App Connection — Root Cause Found

### The Problem
GitHub App installed 2 days ago but "No repositories connected" on PP dashboard. All post-approval actions (commit status, PR comments, check reruns) failing because `getAppTokenForRepo()` returned null — no `gitHubAppRepo` records in DB.

### Root Cause: TWO bugs
1. **Webhook blocked by auth middleware** — `/api/github-app/webhook` was NOT in `PUBLIC_PATHS` in `src/middleware.ts`. Every GitHub webhook delivery was silently rejected with 401 before the route's HMAC verification could run. GitHub has been unable to deliver ANY webhooks since the app was installed.

2. **Callback used wrong token type** — `src/app/api/github-app/callback/route.ts` used the App JWT to call `/installation/repositories`, but that endpoint requires an installation access token. So even the manual OAuth callback flow couldn't fetch repos.

### Fix: PR #119
- Added `/api/github-app/webhook` to PUBLIC_PATHS
- Fixed callback to generate installation access token before fetching repos
- Branch: `hotfix/webhook-auth-and-callback-repos`
