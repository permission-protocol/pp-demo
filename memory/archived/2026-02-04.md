### Chunk C Persistence Update (12:05 MST)
Rod requested persistence layer update:
> "Replace in-memory approval store with Prisma/Postgres... Approvals must survive restarts."

Implemented:
1. **PrismaApprovalStore** - Full ApprovalRequest persistence using existing PermissionApproval model
2. **PrismaPolicyVersionStore** - New PolicySnapshotV1 model for versioned snapshots
3. **Resolution receipt linking** - On resolve, writes receipt linking:
   - escalation receiptId → approvalId → snapshotId before/after
4. **Policy API endpoints**:
   - GET /v1/policy - Get active policy
   - GET /v1/policy/history - Get version history  
   - POST /v1/policy/rollback - Rollback to previous version
   - GET /v1/policy/diff - Compare two snapshots

Key behaviors:
- `allow_once` does NOT mutate policy (snapshotAfter = snapshotBefore)
- `allow_always` applies patch, creates new snapshotId (snapshotAfter differs)
- Only one active snapshot per tenant at a time

Schema changes:
- Extended PermissionApproval with nullable v1 fields
- Extended PermissionReceipt with linkedApprovalId, policySnapshotBefore/After
- New PolicySnapshotV1 model
