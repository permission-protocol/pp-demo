## Marketing Agent Bug Fix

**Root cause found:** `git reset --hard HEAD` resets to current HEAD, but we checkout from `baseSha`. If HEAD ≠ baseSha and file differs between them, git sees "local changes" and refuses.

**Fix (PR #149):** `git reset --hard <baseSha>` instead of HEAD.

PRs created: #147 (stash approach - didn't work), #148 (read/rewrite approach - didn't work), #149 (reset to baseSha - correct fix)
