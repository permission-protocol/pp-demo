## Insights: Lessons learned or breakthroughs
- **The Cache Trap:** High cache write/read ratios (2:1) indicate that dynamic data (timestamps/session IDs) is being injected above the cache boundary, making prompt caching a liability rather than an asset.
- **Prefix Instability Root Cause:** The massive 60k+ token system prompt was repeatedly re-cached because OpenClaw's prompt assembly included a dynamically generated current timestamp *above* the cache breakpoint.
- **Model Selection:** Gemini Flash/Pro handles high-volume tasks efficiently, but Opus 4.6 is still the default for many workflows, driving 90% of Anthropic spend.
- **Pixel-Perfect Implementation:** Using reference HTML with a clear prompt file (`CODEX-PROMPT.md`) allowed Codex to implement a complete 5-screen visual redesign in a single pass with zero type errors.
