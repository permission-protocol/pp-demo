### PR Reviews & Fixes (22:20 - 23:45)

Rod requested a review of recent PRs on the `permission-protocol/app` repo. I identified several bugs and inefficiencies from the last 48 hours:

1. **4 duplicate PR comments** — Root cause: two independent systems (GitHub App webhook + duplicate GitHub Action `pp-gate.yml`) posting comments with different dedup markers.
2. **Stuck "Analyzing..." placeholder** — Root cause: inverted catch block in webhook route caused enrichment failures to leave the placeholder forever.
3. **Redirect Loop** — Root cause: `window.history.replaceState` doesn't update Next.js `useSearchParams`, causing the dashboard to re-trigger the "connected" sync logic.
4. **Token Waste** — Root cause: `maxOutputTokens` was set to 8192 for tiny JSON outputs (~200 tokens).

**Actions Taken:**
- **PR #218 (Merged):** Deleted duplicate `pp-gate.yml`, disabled `post-comment` in `pr-gate.yml` (letting the webhook own comments), and added dedup/error handling to the webhook handler.
