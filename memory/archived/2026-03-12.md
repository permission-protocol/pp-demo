## Key Decisions
- **Approval screen is a decision flow, not a document** — 4 zones: Context (2 sec), Assessment (15 sec), Action (1 sec), Evidence (expandable)
- **80% of approvals should happen without scrolling** — Marco sees green risk, hits Approve
- **Environment theming** — production gets amber accent, staging gets blue. Subconscious priming.
- **Deny flow collapsed** — reject reasons + "require new request" only shown after clicking Deny
- **Verification warnings suppressed** when cause is missing server config (not genuine integrity concern)
