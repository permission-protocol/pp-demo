# PullMatch - Context & History

**Product Concept:**
PullMatch is a mobile-first swiping interface for GitHub pull requests ("Tinder for PRs"). 

**Origin & Stack:**
- **Built:** "Live Sprint" around March 18, 2026.
- **Pattern Used:** "Parallel Codex" pattern (compressing a multi-hour sprint into a single heartbeat cycle by spawning parallel sub-agents for independent features).
- **Core Features Built:** Database, Auth, Discord integration, Rate Limiting, and an AI Engine.
- **Original Name/Domain:** "Tinder for PRs" (`tinderforpr.com`).
- **Rebrand Date:** March 20, 2026 (`pullmatch.com`).

**Current Role:**
PullMatch is currently serving as the primary demo environment for **Permission Protocol**.
- It was used to demonstrate the "Jake flow" (end-to-end PR review workflow).
- Flow: PR opened -> Webhook fired -> PP deploy request created -> PR merge blocked -> PP bot posts rich comment with AI summary + Approve/Reject links -> Click Approve -> Review page -> Approve -> Success -> Back to PR.
- Demo Asset: PR #6 (`feat/hero-refresh`) on `Tinder4PRs/website` was staged as the primary demo recording.
