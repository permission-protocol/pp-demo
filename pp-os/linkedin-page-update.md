### About / Overview (2000 chars max)
```
Permission Protocol is the independent authorization layer for autonomous systems.

AI agents are deploying code, moving money, and mutating infrastructure — but most governance tools live inside the agent runtime. That's a conflict of interest. Authorization must exist outside the agent.

Permission Protocol enforces external approval at the execution boundary. Every irreversible action requires a cryptographic receipt — a signed, time-limited, independently verifiable authorization artifact. No receipt, no deploy. No exceptions.

How it works:
→ Agent requests permission to act
→ A human (or policy engine) reviews and approves
→ Permission Protocol issues a cryptographic receipt
→ The CI pipeline verifies the receipt before execution
→ Every action has an immutable audit trail

Deploy Gate, our open-source GitHub Action, installs in 2 minutes and enforces this at the PR level. Branch protection blocks the merge. The receipt unblocks it. Cryptographic enforcement, not configuration.

We're building the Stripe of AI authority — a single enforcement layer for every agent action that touches the real world.

🔗 github.com/permission-protocol/deploy-gate
```
