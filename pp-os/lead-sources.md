# PP Lead Sources

## High-Value Sources (scan regularly)

### AI Code Review Tool Customers
Best source found so far. Companies using these tools have AI in their code workflow but no governance layer.
- **Greptile** (greptile.com) — customer list, case studies, testimonials
- **CodeRabbit** (coderabbit.ai) — customer list, blog posts about adoption
- **Codacy** — enterprise customers
- **Sourcegraph Cody** — customer stories

### How to scan
- Check customer/testimonials pages monthly
- Search for new blog posts: "[tool] + case study" or "[tool] + adoption"
- Twitter: companies tagging these tools
- GitHub: repos with these tools in workflows

### Why it works
Gap between "AI reviews my code" and "who approved this AI code going to prod" is exactly where PP fits. These companies already trust AI in the loop — they just don't have governance.

## Incident Monitoring
Daily scan for AI code incidents. When a company has a public incident involving AI-generated code, that's the perfect outreach moment.

### Search terms
- "AI generated code" + (incident | bug | outage | broke | production)
- "copilot" + (incident | broke production | reverted)
- "AI agent" + (deployed | unauthorized | merge)
- "LLM" + (code review | production incident)
- Hacker News: AI code governance, AI incidents
- Reddit: r/programming, r/devops, r/ExperiencedDevs
