## Draft Reply

The 'why' framing is the right axis. Static IAM tells you who called the tool. A purpose-bound receipt tells you whether that call was contextually appropriate — two different enforcement primitives.

We implement it as receipt fields: calling agent identity + declared purpose + scope bounds + expiry, signed at request time. If mid-execution intent drifts, the next call generates a new receipt that can be evaluated against the original declared purpose. Drift is detectable, not invisible.
