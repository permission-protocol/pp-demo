# Jake — "The Vibe Coder"

Solo founder or indie dev. Building fast. Ships 2-3x/day. Uses Codex or Claude Code for most code — not because he can't code, but because it's faster. Maybe technical, maybe a vibe coder who reads code but doesn't write it from scratch.

## Stack
- 1-3 repos, probably Next.js or similar
- Vercel/Netlify (push to main = live)
- GitHub
- Codex / Claude Code / Cursor doing the heavy lifting

## His Day
- Tells agent "add Stripe checkout to the pricing page"
- Agent opens PR
- Jake skims the diff (or doesn't)
- Merges. Hopes nothing broke. Repeat 5-10x/day.

## His Fear (even if he won't say it)
- The agent changed something he didn't notice
- His prod database gets wiped (he's seen the tweets)
- He merged something that leaked API keys or broke auth
- Review is basically rubber-stamping

## Why He'd Install PP
- Not compliance or governance (doesn't care)
- Saw the Clinejection tweet about 1.9M rows deleted
- Had his own "oh shit" moment last week
- Wants a gut-check layer faster than reading diffs
- AI summary tells him what the agent *actually* did in plain English

## Why He'd Stay
- Doesn't slow him down (approve in 10 seconds from PR notification)
- Summary catches things he would've missed
- Receipt is proof when cofounder asks "who approved that?"
- Zero config after install

## What He Won't Tolerate
- Dashboard he has to check
- Config files or YAML
- Signup flow longer than GitHub OAuth
- Anything slower than not having PP

## Where He Hangs Out
- r/ChatGPTCoding, r/cursor
- Cursor forums
- Indie Hackers
- X (follows AI coding accounts)
- Show HN reader
- Discord communities (Codex, Claude Code, Cursor)

## Success Moment
Agent opens a PR. Jake gets a GitHub notification. Comment says: *"This PR adds a new API route that exposes user emails without authentication. Risk: HIGH."* Jake goes "holy shit, good catch" and rejects it. That's the moment he tells his friends.

## Failure Moment
Installs PP. Nothing happens for 10 minutes. Has to add a YAML file. Then a secret. Then figure out why the check isn't showing up. Uninstalls. Goes back to merging blind.
