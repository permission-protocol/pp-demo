# Swipe File

Save posts that actually work — organized by platform.

## Structure
- `linkedin/` — LinkedIn posts that stopped the scroll
- `twitter/` — Threads and tweets that sparked debate
- `blog/` — Articles that earned respect
- `hn/` — HN submissions that got traction

## What to save
- The post text
- Why it worked (1-2 sentences)
- Engagement metrics if available
- Date captured

## What NOT to save
- Anything that smells like AI slop
- Posts that went viral for the wrong reasons
- Anything we wouldn't want to be compared to
