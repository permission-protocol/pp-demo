# Publishing Rules

## #published Channel (Discord: 1479864300926668895)

**Every time ANYTHING goes live under PP's name, log it to #published.**

Format:
```
**{emoji} {Platform} — {Type}** ({date})
{One-line description}
<{direct URL}>
```

Emojis:
- 🐦 X (tweets, threads, replies)
- 📝 Blog
- 💬 HN Comment
- 🔴 Reddit
- 💼 LinkedIn (Rod's account)
- 🐙 GitHub (discussions, issues on external repos)
- 📧 Newsletter

## #rod-actions Channel (Discord: 1479863103373185068)

**Every time Rod needs to do something, post it here.**

Rules:
- One action per message
- Always copy-paste ready
- If browser required: include **👉 Open:** direct link at top
- React: ✅ done | ❌ skip | 🔄 revise
- Max 3 pending actions at a time
- Clean up completed items daily

## Content Flow
1. Charles drafts content
2. Auto-approved content → publish → log to #published
3. Human-gated content → post to #rod-actions → Rod executes → Charles logs to #published
4. All crons that publish must log to #published
