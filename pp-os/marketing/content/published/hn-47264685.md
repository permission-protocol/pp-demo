## Draft Comment

Good framing. A few properties we've found you can't retrofit:

**Authorization has to live outside the context window.** Safety constraints in the system prompt get compressed, truncated, or poisoned. Any authorization logic that depends on the agent "knowing" its constraints isn't durable.

**Tool calls need explicit scopes, not ambient permissions.** Most frameworks default to the agent inheriting the full credential set. In regulated environments, that's the entire blast radius on every operation. Scoped, time-bound grants per call is the model that survives audit.

**Audit receipts shouldn't come from the agent.** The agent logging its own actions is like letting a contractor write their own inspection reports. The enforcement layer needs to produce the trail.

**Egress control = tool-call control.** Enumerate and gate what tools an agent can call and with what parameters — you've addressed most of the outbound surface. Hard to retrofit because most frameworks treat tool dispatch as internal logic.

The orgs that get this to production treat authorization as infrastructure, not policy.
