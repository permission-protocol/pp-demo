# PRD: idea-052 — Marketing Site Section Spacing

**Issue:** permission-protocol/site#199  
**Priority:** P2  
**Repo:** permission-protocol/site

## Problem
Excessive empty space (~500px gaps) between homepage sections, especially below badge row and after "The Receipt" section.

## Requirements
- Reduce vertical padding between sections to consistent spacing (80-120px instead of 200px+)
- Check if there are hidden/empty sections causing the gaps
- Footer should feel connected to last content section
- Maintain breathing room — don't cram, just eliminate the void

## Must NOT Do
- Don't change section content or order
- Don't modify the responsive behavior (mobile spacing might be different)
