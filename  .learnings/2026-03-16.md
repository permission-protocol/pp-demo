# Learning: 2026-03-16 (Nightly Reflection)

## Context
Pivot day for Permission Protocol. Strategy correction from app-first to primitive-first. Major consolidation of marketing site and app repos.

## The Lesson
"Polish is the enemy of the Primitive." We spent 8 days polishing a dashboard for a product whose core value (enforcement SDK) wasn't yet bulletproof. The dashboard is useless without the SDK, but the SDK is useful without the dashboard (via CLI/Slack).

## Top 3 Improvements Implemented
1. **The Rebase Train (`scripts/rebase-factory-prs.sh`)**: Automated rebasing of open factory branches against main to prevent "Conflict Cascades."
2. **The Leverage Filter (`SOUL.md`)**: Formalized the prioritization of Primitives (SDK/Action/Onboarding) over Polish (Interface/UX).
3. **Secret Paste Guardrail (`AGENTS.md`)**: Hardened the API key hygiene rule to include proactive scrubbing and alerting when secrets are detected in chat.
