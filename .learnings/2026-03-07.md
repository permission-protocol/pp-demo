# Learnings — 2026-03-07

## 1. The Focus Decision Changes Everything
Rod declared a 28-day single-wedge sprint: AI coding agents + deploy-gate ONLY.
- 13 crons paused. Everything non-deploy-gate is paused.
- FOCUS.md should have been created immediately — it wasn't. Had to be caught in nightly review.
- **Rule:** When a major pivot happens, write the filter document FIRST before doing anything else.

## 2. First Drafts Too Technical for Public Audiences
The LinkedIn post process exposed a consistent weakness: my instinct is to be precise and logical.
Public audiences want to feel something first, understand second.
- The Pentagon-Anthropic piece needed 7 iterations to get the story right.
- Rod posted V5 (the more technical one) — suggesting even V7 may have overcorrected.
- **Rule:** Ask the 3 questions BEFORE writing, not after 5 drafts. Who reads it? What should they feel? What's the one takeaway?

## 3. API Keys Exposed in Discord
Rod pasted 3 API keys directly into #rod-actions chat during the content pipeline build.
- OpenAI key + 2 Gemini keys all visible in channel history.
- I stored them to secrets files correctly but didn't immediately flag the exposure clearly enough.
- Rod still needs to delete those messages.
- **Rule:** Any key pasted in chat = treat as compromised. Store, flag, remind to delete, suggest rotation.

## 4. Next.js Dynamic Route Gotcha
`/api/review/list` was silently matched by `/api/review/[id]` (id = "list").
- No error, just wrong behavior. Subtle and hard to debug.
- Fix: collection endpoints live at a different path level (e.g., `/api/reviews` not `/api/review/list`)
- **Rule:** In Next.js App Router, never put a static segment inside a dynamic route parent if a list/collection endpoint is needed.
