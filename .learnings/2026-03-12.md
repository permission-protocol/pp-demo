# Learning: Codex and the "Missing Import" Trap
**Date:** 2026-03-12
**Context:** During the Batch 1 UX overhaul, Codex generated several components in `page.tsx` but missed necessary imports for new icons and utility functions, leading to 3 type errors.
**Pattern:**
1. **Implicit Imports**: Codex often assumes standard icons or library functions (like `lucide-react` or `clsx`) are already imported or will be auto-imported. 
2. **Post-Codex Lint Check**: Never assume a Codex session finished "cleanly" just because it stopped. Always run a lint/type check (`npm run lint` or `tsc --noEmit`) immediately after a coding agent finishes.
3. **Manual Import Pass**: If a coding agent modifies a large file (like a main `page.tsx`), perform a quick manual scan of the top of the file to ensure new dependencies were actually added to the import block.
4. **Environment Context**: In Next.js/React environments, specifically check for `use client` directives if Codex adds hooks to a file that didn't have them before.
